# Mini POS test generation example

On 25 November 2026 the regression test generation agent produced `mini_pos_generated_scenarios.json` using Groq model `openai/gpt-oss-120b`. The input was a **simulated** change to `sample_projects/mini_pos/billing.py` at commit `94bb21ab12a196f0620cd0dac51a48441e34c1bb`, with changed functions `apply_discount` and `checkout`. The impact report was produced by Mujahidh's `analyze_impact` function. The prompt stated that premium customers receive 10% off and a full refund matches the amount paid; these are example assumptions, not independently approved requirements.

The generated output contains four scenario groups. A human reviewed their code before execution. In a temporary copy of `sample_projects/mini_pos`, each scenario's `test_code` was saved as a separate test file. The copy's root and its `mini_pos` directory were put on `PYTHONPATH` to support the sample's absolute `billing` imports. Running Python 3.12 and pytest 9.2 produced **12 passed, 1 failed**. No product files were changed during this run. A temporary copy is not a security sandbox; review generated code and use proper isolation before execution.

The failed case was `test_checkout_various[0.99-100-premium-89.1]`: exact equality expected `89.1`, while `checkout(0.99, 100, "premium")` returned `89.10000000000001`. This shows the generated assertion failed on the sample implementation; floating-point representation explains the difference. It does not establish a real customer-facing defect or an approved rounding policy. Confirm the money representation and rounding requirements before deciding whether the implementation or assertion should change. Negative amounts and unknown customer types in the generated examples also require business review.

The sample remains a proposed test artifact, not a benchmark or a verified regression from an actual code change. Nafris's current verification runner targets `sample_projects/refund_demo` rather than these generated tests; integration with its report format and the orchestrator remains future work.
